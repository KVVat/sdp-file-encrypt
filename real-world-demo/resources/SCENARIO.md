# 001 ようこそ、エージェント

機関への入局を歓迎するよ、エージェント。
君にはこれから、潜入作戦が命じられる。逐次情報は本システムを介して送られる。
全ては極秘裏にだ、この文書も例外ではない。
画面にあるチェックボックスをクリックすると、暗号文が表示されるはずだ。
今君がみている文書は一時的に複合されたもので、端末に保存されているわけではない。

さて、具体的な指令を送るために、一つ確認といこう。端末を一度ロックしてくれたまえ。
ロック中に暗号文を送らせてもらう。ロック解除後追加の情報が確認できる。
もちろん適切なPINコードと指紋認証を端末に設定してくれていることが前提となる。

```
本アプリでは秘密機関のエージェントに扮し、本ライブラリの機能の現実世界での実装を体験していただけます。
今回確認すべき要件は以下のとおりです。
 - このデータファイルは画像を含め暗号化されたファイルに格納されています
 - ハードウェアに格納されたキーにはUDR(Unlock Device Required)属性が付与されており、端末がロックされている間の複合は不可能です
 - ロック中に受信したデータを暗号化することは可能です。ただしPREFファイルに保存されたKeyPairの親鍵から派生したDEK(Data Encryption Key)を利用するため、少し強度は落ちます。
 - まずは端末をロックして次の指令を受信してみましょう。
```

# 002 素晴らしい

素晴らしい働きだ、エージェント。
適切な端末のロック設定は、端末のセキュリティを維持する上で非常に重要だ。さて極秘指令だが対立組織のビルに潜入して極秘文書を入手することとなる。潜入先では大きな危険が予想される。また、通常の通信は利用できないため特殊な衛星通信のプロトコルが必要だ。このモジュールはすでにインストール済みだ。

ただし、潜入先に到着後。一度端末を再起動して現地からハードウェアレベルでのキャリブレーションが必要になる。何しろ急造で申し訳がない。それでは行動を開始したまえ。次の指示は端末を再起動したときに送らせてもらおう。

```
今回確認すべき要件は以下の通りになります
 - 端末のロックを解除するとKeyPairでの暗号化は即座にハードウェア鍵を利用した暗号化に切り替わります。
 - 次は端末を再起動して最初のロック解除以前(BFU:Before First Unlock)での暗号化を確認してみましょう。
 - 本ライブラリはAndroidのDirectBootをサポートしているため起動直後に受信したデータを暗号化することが可能です。
 - それでは端末の再起動をお願いします!
```
