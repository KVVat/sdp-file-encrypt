**Table.1 Key Materials in the implementation**

| State / Phase | Key Name | Type / Algorithm | Role in Implementation | Related SFR(v3.3)  |
| ----- | ----- | ----- | ----- | ----- |
| (Common) | Data Encryption Key(DEK) | 32-byte (AES-GCM) | Key to encrypt the actual data (content). It is maintained and does not change before or after state transitions. | FDP\_DAR\_EXT.2.1 |
| \[Locked State\] Encryption  | Recipient UDR Key Pair | Asymmetric (EC / P-256) | Asymmetric key for the recipient, stored in AndroidKeyStore. Defined as UDR, But pub key is stored in application pref. | FCS\_CKM.1/FCS\_CKM.2 |
|  | Ephemeral Key Pair | Asymmetric (EC / P-256) | Temporary key generated by software for each encryption. | FCS\_CKM.1 |
|  | Shared Secret | 32-byte (ECDH) | Shared secret calculated from both Key Pairs. | FCS\_CKM.2 |
|  | Asymmetric KEK | 32-byte (HKDF-SHA256) | Key derived from the Shared Secret, used to wrap (encrypt) the DEK. | FCS\_CKM\_EXT.2 |
| \[Unlocked State\] Used for Encryption/Re-encryption upon Unlock | Symmetric UDR Key (used as KEK) | Symmetric (AES-GCM) | Symmetric key stored in AndroidKeyStore. \*Requirement: Only accessible when the screen is unlocked. Uses the UDR Key directly as the KEK to re-wrap (re-encrypt) the DEK. | FDP\_DAR\_EXT.2.4(Transition to unlocked state) |
